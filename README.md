# CTD-Composition-Section-Validator

A Python-based regulatory affairs project that validates CTD Module 3 Composition Sections (P.1) using Object-Oriented Programming, Inheritance, Custom Exceptions, and Logging.

## Features

* Validates composition section data.
* Checks for missing ingredient information.
* Verifies supported CTD version requirements.
* Uses custom exceptions for regulatory validation errors.
* Saves valid records to a log file.

## Concepts Used

* Classes & Objects
* Inheritance
* Method Overriding
* Custom Exceptions
* Exception Handling
* Logging

## Files

* `CTD_Validator.ipynb` – Jupyter Notebook
* `CTD_Validator.py` – Python Script
* `ctd_validated.txt` – Validation Log File

## Learning Outcome

This project demonstrates how CTD Module 3 composition data can be validated programmatically while applying pharmaceutical regulatory concepts, OOP principles, exception handling, and audit trail generation.
